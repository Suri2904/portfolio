# Portfolio

Suryansh Chandel's personal site. Single-page, dark/technical design consistent with [Strata](https://github.com/Suri2904/strata), built to actually describe what's live instead of the default `create-next-app` boilerplate.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion

## Running locally

```bash
npm install
npm run dev
```

## Deploying

Import into Vercel (or reconnect the existing Vercel project's Git integration to this repo) — no environment variables required.
